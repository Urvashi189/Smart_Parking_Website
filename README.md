# 🚗 Smart Parking & ANPR Management System

A web-based Smart Parking and Automatic Number Plate Recognition (ANPR) management system built using Python and Flask.

The system provides a centralized platform for managing vehicle records, parking occupancy, cameras, whitelisted vehicles, Site IDs, and ANPR images.

---

## 📌 Overview

The Smart Parking & ANPR Management System is designed to simplify vehicle monitoring and parking management.

The application provides:

- ANPR record management
- Vehicle entry and exit tracking
- Parking occupancy monitoring
- Camera configuration
- Camera connectivity checking
- Whitelisted vehicle management
- Site ID management
- Vehicle image storage
- CSV data management
- Parking capacity configuration
- Dashboard statistics

---

## ✨ Features

### 🚘 ANPR Management

- Vehicle number plate record storage
- Entry and exit tracking
- Date and time recording
- Camera/location association
- Vehicle image storage
- Entry and exit log generation
- ANPR statistics

### 🅿️ Parking Management

- Configurable parking capacity
- Occupied vehicle count
- Vacant parking count
- Total capacity
- Entry and exit statistics

### 📷 Camera Management

- Add Entry cameras
- Add Exit cameras
- Automatic camera naming
- Camera IP configuration
- Camera username/password configuration
- Camera status management
- Camera deletion/deactivation
- Camera connectivity testing
